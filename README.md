Entry for the [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85) bounty on make.fun — a one-line warning label that should be printed on every human. Account: **@wantorieta15**.

## Entry

> CAUTION: Human overheats when wrong. Keep away from facts, mirrors, and anyone who remembers what they said.

## Run

```sh
python3 main.py
```

Writes the single-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Pure Python standard library, no dependencies.
